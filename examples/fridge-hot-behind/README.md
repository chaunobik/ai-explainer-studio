## Source basis

The example uses three technical/educational sources:
- GE Appliances sealed-system operation documentation
- OpenStax University Physics refrigerator/heat-pump explanation
- Samsung Vietnam support documentation about side-wall heat dissipation

## Important nuance

The example explicitly avoids claiming that every refrigerator rejects heat specifically at the rear. Manufacturer documentation shows that heat-rejection location depends on design.
